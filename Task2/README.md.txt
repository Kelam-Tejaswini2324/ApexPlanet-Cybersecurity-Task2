The objective of this task was to perform reconnaissance, network scanning, firewall configuration, and vulnerability assessment using professional cybersecurity tools.

* NSLOOKUP
* Google Dorking

* Conducted OS Detection
* Configured firewall rules using iptables
* Installed and configured Nessus Essentials
* Performed vulnerability assessment on localhost
